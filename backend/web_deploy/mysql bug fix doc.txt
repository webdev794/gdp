:: 1) Check the log first to find <tablename>:
notepad D:\xampp8-2-12\mysql\data\mysql_error.log

:: 2) Stop MySQL (must be fully stopped before repairing)
taskkill /F /IM mysqld.exe

:: 3) Repair ONLY the one crashed table (replace <tablename>)

cd /d D:\xampp8-2-12\mysql\data\mysql
D:\xampp8-2-12\mysql\bin\aria_chk.exe -r <tablename>

:: 4) Start MySQL again
D:\xampp8-2-12\mysql_start.bat

:: 5) Verify it's actually responding (not just running)
D:\xampp8-2-12\mysql\bin\mysqladmin.exe -h127.0.0.1 -P3306 -uroot ping
